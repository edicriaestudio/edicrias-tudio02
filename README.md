# EDICRIA STUDIO — Landing Page Cinematográfica

Landing page oficial do **EDICRIA STUDIO** com experiência de scroll cinematográfico em tela cheia, componentes em vidro fosco (*frosted glass*), tipografia com drop shadows e performance ultra-otimizada.

## 🚀 Tecnologias

- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide Icons**
- **Canvas Frame Cache** + **Scroll-Driven Animation Engine**

## 📦 Como Rodar Localmente

1. Instale as dependências:
```bash
npm install
```

2. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

3. Gere o build de produção:
```bash
npm run build
```

## 🌐 Deploy na Vercel

1. Suba este projeto para um repositório no seu **GitHub**:
```bash
git init
git add .
git commit -m "feat: initial commit edicria studio landing page"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```

2. Acesse [vercel.com](https://vercel.com) e importe o repositório.
3. O framework preset será detectado automaticamente como **Vite**.
4. Clique em **Deploy**!
